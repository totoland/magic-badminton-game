Sprite importer: PNG sprite sheet → string grids for src/render/sprites.js

Drop an AI-generated sheet (4 columns x 2 rows: back view row, front view row; stand / run1 / run2 / jump). The importer detects the size of the AI's "fake pixels", averages them down to the target size, picks a palette with k-means and cleans specks. Background = top-left pixel colour (or alpha). Source cell and result are shown side by side.
